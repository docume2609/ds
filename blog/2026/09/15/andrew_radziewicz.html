「事実扱い」と「見解」の区分け​

事実扱い​

  1. Andrew Radziewicz（アンドリュー・ラズウィッツ）は、New York City（ニューヨーク市）の消防士や Mortuary（遺体安置所）・Funeral Home（葬儀場）での納棺師としての勤務経歴を持つ。
  2. C5 / CE-5（シー・イー・ファイブ）瞑想を行って霊魂や存在に呼びかけると、首から足先にかけてピリピリとした身体感覚（tingly feeling）が生じ、その直後に空に光や UAP（未確認空中現象）が出現する。
  3. 自身が撮影した UAP 映像は、Dr. Roger Stanovich?（ロジャー・スタノヴィッチ博士?）による MUFON（ミューフォン）の専門的分析を経て認証され、番組『Close Encounters Down Under（クロース・エンカウンターズ・ダウン・アンダー）』で放映された。
  4. 霊媒能力（ミディアムシップ）は常に解放し続けるものではなく、Japanese Zen（日本禅）などの瞑想訓練を通じて自らの意思でオン・オフを切り替えることが可能である。
  5. 葬儀場や遺体安置所で接した故人の霊魂は、Jesus（ジーザス）や God（ゴッド）などの特定宗教の教義に言及することはなく、「すぐ近くにいる」という事実や愛のメッセージのみを伝達する。
  6. Monroe Institute（モンロー研究所）の Gateway Voyage（ゲートウェイ・ヴォヤージュ）瞑想グループに参加し、体外離脱（OBE）や発光する非物質的実体（non-corporeal entities）との接触を体験した。

見解​

  1. 死の直後に現れる「白い光（white light）」は、人間を地球上の再輪廻サイクル（reincarnation cycle）へ留め置くための「罠（trap）」やマトリックス的な制御機構である可能性が高いため、安易に入らず留まって様子を見るべきであると考えている。
  2. 物理的現実は「夢（dream）」や「シミュレーション（simulation）」であり、肉体を離れた非物質的領域こそが本来の「真の現実（true reality）」であると捉えている。
  3. 今後5年〜10年以内に、世界の終わりではなく地球規模の「意識のシフト（shift in consciousness）」や受容する現実の変容が到来すると予測している。
  4. 政府や Military-Industrial Complex（軍産業複合体）による UFO/UAP に関する完全な情報開示（disclosure）は決して果されず、隠蔽の根本原因は悪質な異星人ではなく人間側の不誠実さ（evil humans）にあると推測している。
  5. 地球での生活は、試練や体験を通じて自らの意識の振動数（vibration）を高めるための「学びの場（learning school）」として機能していると見なしている。

不明瞭​

  1. 霊媒活動において、対象者の胸などの周囲に赤色の円といった視覚的シンボルを感知し、潜在的な病気（がん等）の早期予防に役立てられるとする主張（自らの体験に基づく確認事項として提示する一方で、不確定なサジェスチョンや解釈の域を出ない側面もある）。
  2. 夢の中で経験する出来事が、過去の選択の別バージョン（If の人生）や平行現実（parallel realities）を実際に体験している現象なのか、単なる心理的イメージなのかについての解釈（実体的な体験として語りつつも、仮説的な考察の間で揺れている）。
  3. 映画『Jacob's Ladder（ジェイコブズ・ラダー）』を引きつつ、私たちが生きている現世自体が、実はすでに死後の領域で前世の課題を消化している最中であるという説（実感としての語りと、理論的なアイデア・例え話の間で境界が曖昧である）。
  4. 自身が目撃・撮影する UAP や異次元の存在について、肉眼で見える人と見えない人が分かれる現象（長年の瞑想による認知機能の開花・進化という確定的事実として語る一方で、観察機器や個人の感覚差による推測も交じっている）。

アンドリュー・ラジウィッツ：意識、UAP、および死後生存の統合的視点​

エグゼクティブ・サマリー​

本報告書は、元米国沿岸警備隊員であり、ニューヨーク市の消防士、そして葬儀場勤務の経歴を持つアンドリュー・ラジウィッツ氏へのインタビューに基づく、超常現象、UAP（未確認空中現象）、および意識の性質に関する包括的なブリーフィングである。

ラジウィッツ氏は、UFO、精霊、死後の世界を個別の事象ではなく、相互に関連し合った「エネルギー」の現れとして捉えている。同氏の主張の核心は、瞑想や意識の調整を通じてこれらの現象と直接接触が可能であるという点にある。同氏の活動は、MUFON（相互UFOネットワーク）やガリー・ノーラン博士といった専門家による映像分析によって一定の検証を受けており、単なる個人的な主観に留まらない側面を提示している。

主な結論として、政府主導の情報開示は期待できないこと、そして今後5年から10年の間に人類の意識に重大な転換（シフト）が起こる可能性が示唆されている。

1. 現象の統合的アプローチ​

ラジウィッツ氏は、長年の経験を通じて、超常現象を一つの断片的な事象としてではなく、統合されたエコシステムとして理解するに至った。

  • エネルギーの相互接続性: UFO（UAP）、亡くなった親族の霊、意識の投影はすべて同じ源から来ている。瞑想中に亡くなった親族にサインを求めると、空に光（UAP）が現れるといった現象が報告されている。
  • CE-5（第五種接近遭遇）と瞑想: 意識的に接触を試みる「CE-5」の手法と瞑想を組み合わせることで、物理的な物体の出現を誘発できると主張している。
  • 感覚的予兆: 物理的な物体が空に現れる前に、体中に独特の「チクチクする感覚（tingly feeling）」や、首筋の毛が逆立つような感覚を覚える。これは単なる興奮とは異なり、物体の出現を事前に察知するバイオフィードバック的な信号として機能している。

2. 物理的証拠と専門家による検証​

ラジウィッツ氏が撮影した映像や経験は、複数の専門機関や科学者によって分析されている。

3. 葬儀場での経験と死後生存の知見​

ラジウィッツ氏が葬儀場および遺体安置所（モルグ）で勤務した経験は、死生観に独自の洞察を与えている。

  • 宗教的要素の欠如: 霊的な交信において、亡くなった魂が「イエスと一緒にいる」「神のそばにいる」といった宗教的な言及をすることは一度もなかった。彼らの共通のメッセージは「私はすぐそばにいる（I'm right here）」という点に集約される。
  • 「上にある如く、下にもあり」: 地上での性格やエネルギー状態は、死後も維持される傾向がある。現世で苦しんでいた者は、死後も即座にバラ色の状態になるわけではない。
  • 霊媒（ミディアムシップ）の倫理: ラジウィッツ氏は、霊媒能力を「iPhoneの充電」のように管理しており、24時間常に接続されている状態は「 schizophrenic（統合失調症的）」であり、現実的ではないと批判している。また、求められていない相手に対して一方的に霊的メッセージを伝えることは不道徳であるとしている。

4. モンロー研究所と体外離脱​

ラジウィッツ氏は、ロバート・モンローの理論に基づき、ニューヨークのグループで「ゲートウェイ・ヴォヤージュ（Gateway Voyage）」等の瞑想トレーニングを積んでいる。

  • 非肉体的な存在: 瞑想や体外離脱のプロセスにおいて、さまざまな色に輝くエネルギー体や非肉体的な存在（Non-corporeal entities）との遭遇を報告している。
  • 「白い光」に関する議論: 死の直後に現れるとされる「白い光」を、転生のサイクルに引き戻すための「罠」であるとする説（モンローのルーシュ理論等に関連）に対し、ラジウィッツ氏は警戒感を示している。自身のトレーニングに基づき、その光に飛び込むのではなく、自由意志を持って状況を見極めるべきだと述べている。

5. 意識の変容と将来の展望​

インタビューの終盤では、人類の未来と「情報開示」の性質について論じられている。

政府による情報開示の不可能性

軍産業複合体としての政府は、過去80年間にわたる隠蔽や活動を考慮すると、完全な情報開示を行うことは決してないと予測されている。問題の本質は「邪悪なエイリアン」ではなく、それを利用・隠蔽してきた「邪悪な人間」にあるとの見解が示された。

意識のシフト

今後、地球規模での「意識のシフト（転換）」が起こると予測されている。

  • 時期: 今後5年から10年以内。
  • 性質: 世界の終わりではなく、現実の受け取り方の変化。
  • 個人の責任: 知識を共有し、コミュニティを形成することが重要である。ラジウィッツ氏は、他者に依存するのではなく、各個人が自らの意識を高め、責任を持つことを推奨している。

結論的なメッセージ​

この現実は一種の「シミュレーション」や「夢」のようなものであり、死後の世界こそが真の現実である可能性がある。人類は、自らの振動数（バイブレーション）を高め、より高い知性に到達するための「学習の場」としてこの物理世界に存在している。

経歴と背景​

Andrew Radziewicz（アンドリュー・ラズウィッツ）の経歴と背景​

死の直後や NDE / Near-Death Experience（臨死体験）の際に現れる「白い光（white light）」や光のトンネルに関して、Andrew Radziewicz らは従来の神聖なイメージとは異なる警鐘を鳴らしています。David Parker?（デイヴィッド・パーカー?）や Caspian?（キャスピアン?）といった他の体験者の証言や Monroe Institute（モンロー研究所）での探求を踏まえ、その光は人間を地球上の再輪廻サイクル（reincarnation cycle）へ繰り返し連れ戻し、感情エネルギー（Luch / ルーシュ）を採取・維持するための罠（trap / matrix style thing）である可能性が議論されています。
光の中から亡くなった親族（祖母など）の声や姿（screen / 偽装）が提示されて誘惑された場合であっても、即座に飛び込むのではなく、自由意志を行使して一定時間留まり（wait it out）、状況を観察・見極める姿勢が重要であると強調されています。また、Monroe Institute の Gateway Voyage（ゲートウェイ・ヴォヤージュ）瞑想などを通じた非物質的実体（non-corporeal entities / The Others）との接触体験により、恐れや好戦的な意図を持たずに平和的な意識で望む限り、これらの異次元存在との安全な相互作用が可能であることが実証されています。

未来の展望と「意識のシフト」​

政府開示の限界と人間側の責任​

UFO/UAP 現象や異次元の存在に関する未来の展望として、Andrew Radziewicz は政府や military-industrial complex（軍産業複合体）による公式なディスクロージャー（情報開示）が完全に果たされることは決してないという見解を示しています。真実が隠蔽され続ける根本的な要因は「悪意ある宇宙人（evil aliens）」にあるのではなく、事実を遮蔽し責任転嫁を続ける「人間側の悪や不誠実さ（evil humans）」にあると指摘されています。外部の公的機関による開示を待つのではなく、体験者個々人が事実を客観的に認識し、自己責任を持つことの必要性が説かれています。

意識のシフト（Shift in Consciousness）とコミュニティの形成​

近い未来（5年〜10年以内）において、破滅的な世界の終わり（end of the world）ではなく、Age of Aquarius（エイジ・オブ・アクエリアス / 水瓶座の時代）への移行に伴う地球規模の「意識のシフト（shift in consciousness）」や大きな出来事（event / change in what we receive）が到来すると予見されています。
この大きな変容期を迎えるにあたり、ネット上のデマや無価値な情報（nonsense / lies）に惑わされず、各自が自らの体験と意識を高め（raise vibration）、体験を恐れずにオープンに共有し合うことが求められます。社会的な孤立や無理解を恐れず、「仲間を見つける（find the others）」ことで、志と意識を同じくする強固なコミュニティを築き上げておくことが、未来の変容に対応するための最重要な準備として提示されています。
